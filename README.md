# gognakamaya-dev.github.io

Personal site: essays, a bookshelf, and work. Built with Jekyll, which GitHub Pages runs automatically.

See **WRITING-GUIDE.md** for how to add essays and books.

- `_essays/` essays, one Markdown file each
- `_data/books.yml` the bookshelf
- `_data/work.yml` experience, projects, awards
- `_config.yml` name, links, email
- `assets/css/site.css` all the styling
