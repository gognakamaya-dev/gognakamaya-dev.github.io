This file shows everything an essay can do. It's set to `published: false`, so it **won't appear on your live site**. Copy it, rename it, write, and change that line to `true` (or delete it).

Write in plain Markdown. A blank line starts a new paragraph. *Italics* and **bold** work the way you'd expect, and so do [links](https://github.com/gognakamaya-dev).

## Subheadings use two hashes

Margin notes are the red-pen scribbles that sit beside the text on a wide screen and drop in below the line on a phone.<span class="margin-note">Like this one. Wrap a short aside in a span with class margin-note.</span> They're good for asides that would break the flow of a sentence.

Footnotes work too, for citations or longer tangents.[^1]

> Block quotes are for other people's words. Start the line with a greater-than sign.

You can add an image by dropping it in `assets/img/` and writing:

```
![What the image shows](/assets/img/your-photo.jpg)
```

And code, if an essay needs it:

```c
HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
```

---

A line of three dashes draws a break between sections.

[^1]: Footnotes collect at the bottom of the essay, with a link back to where you were.
